# Texturas aportadas por el usuario

Cuatro ZIP con dos capas equipadas cada uno, importados como datos PNG:
`venus`, `vacuum`, `abyssal`, `cryo`. `manifest.json` registra nombres y SHA-256
de los archivos ZIP y de cada PNG. Las imágenes de estas carpetas son copias
exactas de las entradas originales. No se ejecuta contenido de los ZIP.

El importador conserva estas imágenes y configura capas de equipo nativas sobre
un forro completo. Véase `docs/suit-redesigns.md` y
`python3 tools/import_suit_redesigns.py` para reproducir la instalación.
